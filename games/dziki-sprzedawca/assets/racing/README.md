# Dziki Grand Prix car

Creator: **Kenney**, Racing Kit — https://kenney.nl/assets/racing-kit

License: **CC0 1.0**, https://creativecommons.org/publicdomain/zero/1.0/

The bundled `race-car-v1.glb` is the pack's `raceCarWhite.glb`, downloaded from the public shorepine/kenney mirror. Its exact source URL, size and SHA-256 are recorded in `asset-info.json`.

The model has embedded colour materials, with no external textures. The game shares its geometry across ten paint variants, darkens the tyres and glazing, and adds race numbers. All vehicles use the same acceleration, braking and maximum speed from `racing.js`.
